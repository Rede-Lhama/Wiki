# Screenshare



Durante a partida, um membro da equipe com cargo de **Telador ou superior** poderá solicitar uma inspeção no computador do jogador.

A verificação tem como objetivo identificar possíveis arquivos, programas ou modificações relacionados a cheats, sempre buscando preservar a privacidade e os dados pessoais do jogador.

> O jogador possui o direito de recusar uma Screenshare. Entretanto, a recusa poderá resultar em **punição ou banimento permante**, conforme as regras da Rede Lhama.

### AnyDesk

A inspeção poderá ser realizada através do **AnyDesk**, uma ferramenta de acesso remoto utilizada para permitir que o membro da equipe acompanhe o procedimento de verificação.

O jogador deverá:

1. Baixar o AnyDesk.
2. Executar o programa.
3. Informar à equipe o código exibido na tela.
4. Aguardar as instruções do responsável pela Screenshare.

[Baixar AnyDesk](https://anydesk.com/pt/downloads/windows)

O prazo máximo para iniciar a instalação e execução do programa será de **3 minutos** após a solicitação.

> Recomendamos que o AnyDesk já esteja instalado previamente para evitar atrasos durante uma verificação.

### Verificação de Arquivos

A análise é direcionada exclusivamente à identificação de arquivos e programas relacionados a trapaças ou vantagens indevidas.

Durante o procedimento, poderão ser analisados arquivos como:

| Tipo                      | Exemplos                                                       |
| ------------------------- | -------------------------------------------------------------- |
| **Executáveis**           | `.exe`                                                         |
| **Mods**                  | `.jar`                                                         |
| **Arquivos relacionados** | Arquivos associados a clients, cheats ou ferramentas suspeitas |
| **Processos**             | Processos relacionados a ferramentas de trapaça                |
| **Registros**             | Informações técnicas necessárias para a verificação            |

A equipe deverá limitar a análise aos elementos relacionados à possível utilização de trapaças.

{% hint style="info" %}
Arquivos, fotos, documentos, conversas e demais informações pessoais que não tenham relação com a verificação não são o objetivo da Screenshare.
{% endhint %}

### Tentativa de Bypass

{% hint style="danger" %}
Qualquer tentativa de ocultar, apagar, modificar ou manipular informações durante uma Screenshare poderá ser enquadrada como **tentativa de bypass**.

A punição será aplicada conforme a regra correspondente da Rede Lhama.
{% endhint %}

### Ferramentas de Verificação

Durante uma Screenshare, a equipe poderá utilizar ferramentas públicas e especializadas para auxiliar na identificação de possíveis trapaças.

Essas ferramentas poderão realizar verificações mais aprofundadas em arquivos, processos e informações técnicas relacionadas ao Minecraft.--

{% hint style="warning" %}
A execução ou utilização das ferramentas deverá ocorrer somente quando solicitada pelo membro da equipe responsável pela verificação.

A utilização dessas ferramentas por conta própria com o objetivo de descobrir ou evitar os métodos utilizados pela equipe poderá ser interpretada como **tentativa de bypass**.
{% endhint %}

### Regras da Screenshare

As seguintes ações são proibidas durante uma Screenshare:

| Na Screenshare é proibído:                                  |
| ----------------------------------------------------------- |
| Executar ou modificar arquivos após o início da Screenshare |
| Reiniciar processos enquanto o Minecraft estiver aberto     |
| Apagar arquivos executáveis após iniciar o Minecraft        |
| Utilizar máquina virtual durante a verificação              |
| Manter executáveis de cheats no computador                  |
| Desativar serviços necessários para a verificação           |
| Gravar ou realizar clipes da Screenshare sem autorização    |
| Alterar ou apagar chaves do Registro do Windows             |

#### Serviços

Durante a verificação, os seguintes serviços não poderão estar desativados:

* `pcasvc`
* `SysMain`
* `DPS`
* `BAM`
* `DusmSvc`

### Durante a Verificação

Após o início da Screenshare, siga todas as instruções fornecidas pelo membro da equipe responsável.

{% hint style="danger" %}
**Não execute, modifique, mova ou apague arquivos durante a verificação.**

Qualquer alteração realizada após o início do procedimento poderá ser interpretada como tentativa de ocultação de informações e resultar em punição.
{% endhint %}

A gravação do procedimento, quando necessária, deverá ser realizada pelo membro da equipe responsável pela Screenshare para garantir que eventuais contestações possam ser analisadas posteriormente.

### Recusa da Screenshare

O jogador possui o direito de recusar a realização da verificação.

Entretanto, a recusa de uma Screenshare ou a recusa em executar ferramentas solicitadas pela equipe poderá resultar em **restrição da conta ou punição**, de acordo com as regras vigentes.
