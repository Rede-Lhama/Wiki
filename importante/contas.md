# Contas

### Senha

Utilize sempre uma **senha forte e exclusiva**.

Recomendamos evitar:

* Nome ou apelido
* Data de nascimento
* Nome do Minecraft
* Sequências simples de números
* Senhas utilizadas em outros serviços

{% hint style="danger" %}
**Nunca entregue sua senha para ninguém**, a STAFF nunca solicitará a sua senha.
{% endhint %}

### Plataformas

As contas da Rede Lhama podem utilizar diferentes plataformas e tipos de acesso.

| Plataforma          | Tipo de acesso |
| ------------------- | -------------- |
| **Java Edition**    | Original       |
| **Java Edition**    | Pirata         |
| **Bedrock Edition** | Bedrock        |

As contas Java possuem duas formas de autenticação: **Original** e **Pirata**.

Caso deseje alternar entre os tipos de login, utilize os comandos:

`/original`

`/pirata`

{% hint style="info" %}
Certifique-se de utilizar o modo correspondente ao tipo de conta que está utilizando. Caso tenha dúvidas, entre em contato com a equipe.
{% endhint %}

### Troca de Nick

A alteração do nick pode resultar em uma transferência automática ou manual dos dados, dependendo da plataforma de origem e destino.

| Plataforma de origem | Plataforma de destino | Transferência automática |
| -------------------- | --------------------- | :----------------------: |
| Java Original        | Java Original         |             ✓            |
| Bedrock              | Bedrock               |             ✓            |
| Java Original        | Java Pirata           |             ❌            |
| Java Pirata          | Java Original         |             ❌            |
| Java Original/Pirata | Bedrock               |             ❌            |
| Bedrock              | Java Original/Pirata  |             ❌            |

#### Java Original → Java Original

Caso altere seu nick através do `minecraft.net`, os dados poderão ser transferidos automaticamente.

Para isso:

1. Sua conta deve estar utilizando `/original`.
2. O novo nick não pode ter sido registrado anteriormente por outro jogador na Rede Lhama.

{% hint style="warning" %}
Essa limitação existe como medida de proteção contra roubo e transferência indevida de contas.
{% endhint %}

#### Transferência Manual

Nos casos em que a transferência automática não é possível, será necessário adquirir o produto **Troca de Conta** e abrir um ticket no Discord solicitando o procedimento.

O prazo para transferência é de até **3 dias úteis** após a compra.

{% hint style="warning" %}
Todos os dados serão transferidos, com exceção da **data de registro**, que passará a apresentar a data de registro da nova conta.
{% endhint %}

### Proteção da Conta

A melhor forma de proteger sua conta é vinculá-la ao **Discord da Rede Lhama**.

#### Vinculação com o Discord

1. Entre no servidor da Rede Lhama pelo Minecraft.
2. Faça login na sua conta.
3. Execute:

`/discord conectar`

4. Um código de **4 dígitos** será enviado no chat.
5. Acesse o Discord da Rede Lhama.
6. Entre no canal destinado aos comandos.
7. Execute:

`/conectar <código>`

8. Substitua `<código>` pelo código recebido no Minecraft.

{% hint style="success" %}
Após a conclusão, sua conta estará sincronizada com o Discord e poderá receber os cargos correspondentes à sua conta dentro do servidor.
{% endhint %}

### 🔐 Recuperação da Conta

Perdeu sua senha?

A Rede Lhama possui métodos diferentes de recuperação dependendo de a conta estar ou não vinculada ao Discord.

#### Conta vinculada

1. Acesse o Discord da Rede Lhama.
2. Entre no canal de **Tickets**.
3. Selecione a categoria **Esqueci minha senha**.
4. Clique em **Recuperar senha**.
5. Uma nova senha será gerada automaticamente pelo sistema.

#### Conta não vinculada

Caso sua conta não possua nenhuma vinculação, ainda será possível solicitar uma **recuperação manual** através do Discord.

Um formulário será disponibilizado para que você forneça informações capazes de comprovar a propriedade da conta.

{% hint style="info" %}
Forneça o máximo possível de informações verdadeiras que você conseguir lembrar. Quanto mais informações válidas forem apresentadas, maior será a possibilidade de a equipe confirmar a propriedade da conta.
{% endhint %}

{% hint style="danger" %}
**Nunca forneça informações falsas durante uma recuperação.**

A equipe poderá recusar solicitações que não apresentem informações suficientes para comprovar a propriedade da conta.
{% endhint %}
