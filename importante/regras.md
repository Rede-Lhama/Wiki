# Regras

Este documento estabelece as normas de convivência, utilização do Discord e comportamento dentro do servidor Minecraft.

> Leia atentamente todas as regras. O desconhecimento das normas não isenta o jogador de uma eventual punição.

### Aplicação das regras

As regras estão divididas em duas categorias:

* **Regras Gerais:** aplicadas no Discord e no Minecraft.
* **Regras do Minecraft:** aplicadas exclusivamente dentro do servidor.

A equipe poderá considerar o histórico do jogador, a gravidade da infração, as circunstâncias do caso e a reincidência ao definir uma punição.

### Tabela de reincidência

A repetição de uma mesma infração poderá resultar no agravamento progressivo da punição.

|     Ocorrência    | Aplicação                           |
| :---------------: | ----------------------------------- |
| **1ª ocorrência** | Punição inicial definida pela regra |
| **2ª ocorrência** | Punição agravada                    |
| **3ª ocorrência** | Punição severa                      |
| **4ª ocorrência** | Punição máxima ou permanente        |

> A contagem de ocorrências é realizada com base no histórico disciplinar do jogador. Infrações diferentes também poderão ser consideradas no agravamento de uma punição quando houver reincidência frequente.

### Regras Gerais

#### 01. Respeito

É proibido realizar ofensas graves, perseguições, assédio moral ou qualquer comportamento que tenha como objetivo intimidar, constranger ou prejudicar outro membro ou integrante da equipe.

| Ocorrência | Punição         |
| :--------: | --------------- |
|   **1ª**   | Mute 3 dias     |
|   **2ª**   | Mute 7 dias     |
|   **3ª**   | Mute 30 dias    |
|   **4ª**   | Mute Permanente |

#### 02. Conteúdo Inapropriado

É proibido enviar links, imagens, vídeos ou mensagens contendo NSFW, conteúdo +18, gore, violência extrema ou qualquer material considerado inadequado para a comunidade.

Discussões políticas também devem ser evitadas.

| Ocorrência | Punição        |
| :--------: | -------------- |
|   **1ª**   | Mute 30 dias   |
|   **2ª**   | Mute 60 dias   |
|   **3ª**   | Ban 30 dias    |
|   **4ª**   | Ban Permanente |

#### 03. Poluição com Mensagens

É proibido realizar spam, flood, enviar caracteres repetidamente ou utilizar CAPS LOCK de maneira excessiva.

Cada canal deve ser utilizado de acordo com sua finalidade.

| Ocorrência | Punição         |
| :--------: | --------------- |
|   **1ª**   | Mute 8 horas    |
|   **2ª**   | Mute 3 dias     |
|   **3ª**   | Mute 7 dias     |
|   **4ª**   | Mute Permanente |

#### 04. Divulgação

É proibida qualquer forma de divulgação sem autorização prévia da Administração.

Isso inclui servidores, comunidades, links externos, produtos, ou qualquer outro tipo de divulgação, tanto em canais públicos quanto através de mensagens privadas.

| Ocorrência | Punição         |
| :--------: | --------------- |
|   **1ª**   | Mute 3 dias     |
|   **2ª**   | Mute 15 dias    |
|   **3ª**   | Mute 30 dias    |
|   **4ª**   | Mute Permanente |

#### 05. Desordem no Chat

É proibido causar tumultos, iniciar discussões tóxicas, provocar continuamente outros jogadores ou apresentar comportamentos que prejudiquem o ambiente da comunidade.

Conflitos pessoais devem ser resolvidos através do sistema de suporte.

| Ocorrência | Punição         |
| :--------: | --------------- |
|   **1ª**   | Mute 8 horas    |
|   **2ª**   | Mute 3 dias     |
|   **3ª**   | Mute 30 dias    |
|   **4ª**   | Mute Permanente |

#### 06. Discriminação e Atos Depreciativos

É terminantemente proibido qualquer ato de racismo, homofobia, xenofobia, intolerância religiosa ou qualquer outra forma de discriminação.

Também é proibido humilhar ou ridicularizar intencionalmente outro jogador.

| Ocorrência | Punição                                  |
| :--------: | ---------------------------------------- |
|   **1ª**   | Mute 30 dias                             |
|   **2ª**   | Mute 60 dias                             |
|   **3ª**   | Ban 30 dias + mute 30 dias após regresso |
|   **4ª**   | Ban Permanente                           |

### Regras do Minecraft

#### 07. Hacks, Cheats ou Vantagem Desleal

É proibido utilizar hacks, clientes modificados, macros ilegais, autoclickers, aplicativos externos ou texturas que proporcionem vantagem indevida.

Exemplos:

* Fly
* KillAura
* AutoTotem
* X-Ray
* Reach
* AimAssist
* Entre outras formas de vantagem desleal

| Ocorrência | Punição        |
| :--------: | -------------- |
|   **1ª**   | Ban 7 dias     |
|   **2ª**   | Ban 30 dias    |
|   **3ª**   | Ban 120 dias   |
|   **4ª**   | Ban Permanente |

#### 08. Exploração de Bugs ou Falhas

É proibido utilizar bugs, glitches ou falhas do jogo ou servidor para obter vantagens, duplicar itens, prejudicar jogadores ou interferir na economia.

Qualquer falha encontrada deverá ser comunicada imediatamente à equipe.

| Ocorrência | Punição                |
| :--------: | ---------------------- |
|   **1ª**   | Ban 30 dias + Reset    |
|   **2ª**   | Ban 60 dias + Reset    |
|   **3ª**   | Ban 120 dias + Reset   |
|   **4ª**   | Ban Permanente + Reset |

#### 09. Comércio Externo (CME)

É proibido comercializar contas, itens, cash ou serviços relacionados ao jogo utilizando dinheiro real fora dos meios oficiais disponibilizados pela Rede Lhama.

| Ocorrência | Punição        |
| :--------: | -------------- |
|   **1ª**   | Ban Permanente |
|   **2ª**   | Ban por IP     |

#### 10. Griefing

É proibida a criação de construções, placas, banner ou símbolos relacionados a facções criminosas, apologia a crimes, atos ilegais ou NSFW, símbolos de ódio, fascismo ou nazismo. Também é proibído colocar blocos aleatórios, explodir mapas, entre outros...

| Ocorrência | Punição        |
| :--------: | -------------- |
|   **1ª**   | Ban 30 dias    |
|   **2ª**   | Ban 60 dias    |
|   **3ª**   | Ban 120 dias   |
|   **4ª**   | Ban Permanente |

#### 11. Nicks, Skins e Nomes de Clãs

É proibido utilizar skins, capas, nicks ou nomes de clãs contendo conteúdo sexual, NSFW, apologia a crimes, termos discriminatórios ou conteúdo ofensivo.

O jogador deverá realizar a alteração solicitada pela equipe.

| Ocorrência | Punição        |
| :--------: | -------------- |
|   **1ª**   | Ban Permanente |
|   **2ª**   | Ban Permanente |
|   **3ª**   | Ban Permanente |
|   **4ª**   | Ban por IP     |

> A punição poderá ser encerrada ou revertida após a alteração do nick, skin ou nome do clã, quando aplicável.

#### 12. Anti-Jogo e AFK Indevido

É proibido permanecer AFK propositalmente durante eventos ou combates, aliar-se a equipes adversárias, trollar partidas, realizar feed intencionalmente ou atrapalhar deliberadamente o progresso e a experiência de outros jogadores.

| Ocorrência | Punição        |
| :--------: | -------------- |
|   **1ª**   | Ban 7 dias     |
|   **2ª**   | Ban 15 dias    |
|   **3ª**   | Ban 30 dias    |
|   **5ª**   | Ban Permanente |

### Agravamento de punições

{% hint style="warning" %}
As punições apresentadas nas tabelas representam a progressão padrão para cada infração. A Administração poderá aplicar uma punição superior à prevista quando a gravidade da situação justificar.
{% endhint %}

Infrações extremamente graves poderão resultar em **banimento permanente ou por IP já na primeira ocorrência**.

O histórico disciplinar do jogador também poderá ser considerado na aplicação de novas punições.

### Bom senso

Nem todas as situações podem ser previstas ou descritas individualmente neste documento.

{% hint style="danger" %}
**Não é porque algo não está escrito nas regras que significa que é permitido.**

Utilize o bom senso, respeite os demais jogadores e contribua para manter uma comunidade saudável.
{% endhint %}

### Denúncias

Caso presencie um jogador infringindo alguma das regras, utilize o sistema oficial de denúncias da Rede Lhama.

Ao realizar uma denúncia, forneça o máximo de informações possível e apresente provas que permitam à equipe analisar corretamente a situação.\
Denúncias só serão aceitas com provas dentro do servidor. Todas as prints devem ser fullscreen (tela cheia). prints dentro do jogo só serão aceitas caso contenham a scoreboard totalmente visível.

Denúncias falsas ou provas manipuladas poderão resultar em punição severa.

### Revisão de Punições

Caso considere que uma punição tenha sido aplicada incorretamente ou deseja ver as provas, o jogador deverá utilizar o comando `/apelar`.

A equipe responsável analisará o caso com base nas provas disponíveis e poderá manter, reduzir, alterar ou remover a punição.

> **A decisão final sobre uma punição ou revisão pertence à Administração da Rede Lhama.**
