# Anti-Cheat

Para garantir um ambiente seguro e competitivo, utilizamos o **Vulcan Anti-Cheat**, um dos principais sistemas de proteção contra trapaças disponíveis atualmente para servidores Minecraft.&#x20;

O Vulcan é utilizado por **milhares de servidores** e foi desenvolvido para identificar comportamentos incompatíveis com as mecânicas legítimas do jogo, atuando principalmente através da análise de pacotes enviados pelo cliente.

> O Vulcan possui suporte para diversas versões do Minecraft e conta com verificações específicas para diferentes categorias de trapaças.

### 🔎 O que é o Vulcan?

O [**Vulcan Anti-Cheat**](https://vulcanac.net/) é um sistema avançado de detecção desenvolvido para identificar e combater jogadores que utilizam modificações ou ferramentas que proporcionem vantagens indevidas.

O sistema trabalha de forma contínua durante a jogabilidade, analisando informações enviadas pelo cliente e comparando o comportamento do jogador com os limites esperados do Minecraft.

{% hint style="success" %}
Na Rede Lhama, o Vulcan é uma das principais camadas de proteção utilizadas para preservar a competitividade e impedir que jogadores obtenham vantagens desleais.
{% endhint %}

Entre as categorias de detecção estão:

| Categoria    | Exemplos                                              |
| ------------ | ----------------------------------------------------- |
| ⚔️ Combate   | KillAura, Reach, Aim, AutoClicker, Criticals          |
| 🏃 Movimento | Fly, Speed e outros comportamentos anormais           |
| 🖱️ Cliques  | Padrões anormais de cliques                           |
| 🧍 Jogador   | Comportamentos incompatíveis com o jogo               |
| 📦 Pacotes   | Manipulações e comportamentos anormais de comunicação |

O Vulcan possui uma ampla variedade de verificações e utiliza análise de pacotes através do **PacketEvents** para auxiliar na identificação de comportamentos suspeitos.

### Como funciona?

O sistema permanece ativo durante a jogabilidade e realiza verificações constantemente.

Quando um comportamento suspeito é identificado, o Vulcan registra informações relacionadas à ocorrência e pode gerar uma detecção para análise da equipe ou aplicação de uma ação configurada no servidor.

A quantidade de verificações e o comportamento do sistema podem ser configurados de acordo com as necessidades do servidor.

{% hint style="info" %}
O sistema anti-cheat não depende exclusivamente de uma única detecção. A equipe pode analisar os dados registrados pelo sistema antes de tomar medidas administrativas, especialmente em situações que possam envolver condições anormais de conexão ou jogabilidade.
{% endhint %}

### Sistema de Detecção

Uma detecção do Vulcan não significa necessariamente que uma punição permanente será aplicada imediatamente.

As informações registradas pelo sistema podem ser analisadas pela equipe responsável para determinar se o comportamento apresentado é compatível com uma tentativa de obtenção de vantagem indevida.

{% hint style="warning" %}
Nenhum sistema anti-cheat é completamente infalível. O próprio projeto Vulcan reconhece que falsos positivos e bypasses podem ocorrer, motivo pelo qual situações suspeitas podem ser encaminhadas para análise da equipe.
{% endhint %}

### Verificação de Jogadores

Em determinadas situações, a equipe poderá solicitar uma verificação adicional para investigar suspeitas de trapaça.

Essa verificação poderá ser realizada através do procedimento de [**Screenshare**](../importante/screenshare.md), seguindo as regras estabelecidas pela Rede Lhama. A recusa ou tentativa de manipulação do processo poderá resultar em medidas administrativas conforme as regras da comunidade.

### Falsos Positivos

Condições externas podem influenciar determinadas verificações, como:

* Instabilidade na conexão;
* Ping elevado;
* Oscilações de conexão;
* Problemas de desempenho;
* Comportamentos específicos de determinados clientes;
* Configurações incomuns de hardware ou periféricos.

Por esse motivo, uma detecção isolada pode ser analisada pela equipe antes da aplicação de determinadas punições.

### Apelação

Você possui o direito de solicitar uma **revisão da punição** através do sistema de apelação da Rede Lhama
